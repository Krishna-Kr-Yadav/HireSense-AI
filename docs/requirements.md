# HireSense AI - Requirements

## Problem Statement

Students often struggle with:
- Resume optimization
- Identifying skill gaps
- Interview preparation
- Tracking placement readiness

## Objectives
Build an AI-powered platform that helps students:
- Analyzes resume
- Match skills with JD
- Generate interview questioins
- Receive personalized recommendations

## Functional Requirements

### Authentication
- User Registration
- User Login
- JWT Authentication

## Resume Module
- Upload PDF Resume
- Extract Resume Content
- Analyze Resume

### Skill Gap Analysis
- Compare resume with JD
- Identify missing skills

### Interveiw Preparation
- Generate interview questions

### Dashboard
- Display progress metrics

## Non Functional Requirements
- Responsive UI
- Secure Authentication
- Fast API Response
- Scalable Architecture
