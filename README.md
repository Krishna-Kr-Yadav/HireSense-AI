# Problem
Many students:
- Don't know whether their resume is good enough.
- Apply to jobs without understanding skill requirements.
- Struggle to prepare for interviews.
- Lack personalized guidance.

# HireSense AI
AI-powered placement preparation platform that helps students:
- Assess their resume
- Identify skill gaps
- Prepare for interviews 
- Track their readiness for internships and placements

## Project Overview
HireSense AI helps students by:
- Analyzing resumes against job descriptions (JD)
- Identify missing skills and knowledge gaps
- Providing personalized improvement suggestions
- Generating interview questions based on skills, projects, and target roles
- Recommending learning resources for missing skills

## Features
- Resume Analysis
- Resume Improvement Suggestions
- Skill Gap Detection
- Job Role Matching
- AI-Generated Interview Questions
- Personalized Learning Recommendations
